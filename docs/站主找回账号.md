# 站主协助找回账号

先与本人核实身份，再登录对应网站的站点维护页。打开“协助找回业务账号”，点“查看登录名”查找账号，或点“重置密码”，选中账号并按提示确认。若忘记的是站主自己的维护密码，请从服务器终端领取新的本站短时码，直接登录或重设站主密码。

使用服务器终端时，按下方对应平台操作。只忘了登录名时，查到后把该登录名单独告诉本人即可。新密码只在终端的隐藏提示中输入，不要写进命令行。

### Ubuntu

进入本站 `docker-compose.yml` 所在的目录，查看登录名、启停状态和角色。

```sh
docker compose exec api python3.12 /app/deploy/api_entrypoint.py list-users
```

需要重置密码时，运行下面的命令。按提示输入刚核实的登录名，再输入同一个新密码两次。输入密码时屏幕没有回显。

```sh
docker compose exec api python3.12 /app/deploy/api_entrypoint.py reset-password
```

如果建站时使用了 `docker compose -p 项目名`，这两条命令也使用相同的 `-p 项目名`。

### 群晖

从 Container Manager 的「项目」找到本站的项目名和目录。用管理员账号登录群晖 SSH 终端，进入该目录。以下示例使用项目名 `gift-ledger`，执行时换成本站实际项目名。

```sh
sudo docker compose -p gift-ledger exec api python3.12 /app/deploy/api_entrypoint.py list-users
```

需要重置时执行下面的命令，按提示填写登录名和新密码。若 SSH 提示 `sudo` 密码，先输入群晖管理员密码。

```sh
sudo docker compose -p gift-ledger exec api python3.12 /app/deploy/api_entrypoint.py reset-password
```

### 怎么确认成功

终端提示指定账号的密码已重置。让本人打开本站网址，用原登录名和新密码重新登录，核对一笔熟悉的往来。旧密码和原有会话随重置失效。名单里显示「停用」的账号继续保持停用。

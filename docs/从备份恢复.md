# 往来有礼 · 从备份恢复

这份说明用于把账本带到另一座新站。先准备一个已启动、尚未注册用户的空站，记下它的 HTTPS 网址、项目名和 YAML 所在的文件夹。若旧站仍在使用，请先暂停记账并做最后一次备份，记下最后一笔和当时的收支合计，方便核账。

## 在 Mac 上准备备份和钥匙

1. 找到备份成功时显示的整份加密备份。单份 YAML 站点的成品在站点文件夹的 `backups/artifacts/备份编号/` 中。把整个编号文件夹保存到 Mac 或另一块盘。旧工具导出的五文件 ZIP 也可以直接选择。
2. 准备**创建这份备份时对应的 age 私钥**，保存在 Mac 本机或直连盘上，仅给自己的 Mac 账号读取权限。原钥匙与离机备份分开保管。
3. 在 Mac 打开同版本的恢复工具目录。工具需要 Python 3、SSH，以及本机的 `age` 和 `age-keygen`；也可使用已经启动、已载入该版本备份镜像的 Docker Desktop。

## 选择备份，确认目标

在工具目录执行下面一条命令。把示例中的 SSH 用户和地址、项目路径、项目名换成**新站**的实际值。SSH 用户需要能在新站运行 Docker，系统提示时可通过 sudo 确认。

```sh
python3 mac_restore.py --host siteadmin@192.168.1.20 --project-dir /volume1/docker/gift-ledger --project gift-ledger
```

在 Mac 的选择窗口依次选中备份目录或 ZIP、对应的原钥匙。程序核验五件文件、实际解密，并检查目标有没有已有账本。看到源站名称、笔数、目标网址和目标实例后，核对网址，输入“恢复”。若要在写入前退出，直接回车。连接中断后，用同一份备份和同一目标再次运行。

## 核账后切换

看到“已核对 … 笔往来”后，用手机或电脑打开**新站**网址。按一页安装说明核对并信任新站自己的公开证书，用旧站的账号、原密码登录，核对最后一笔、收支合计，以及自己熟悉的联系人和事件。核对一致后，再把日常记账入口切换到新站。

## 第一次给本站登记日常备份钥匙

首次备份前，在 Mac 的同版本工具目录执行下行命令。更换 SSH 地址、项目路径和项目名。程序在你的 Mac 个人目录创建一把新钥匙，并将副本加密交给本站保管。

```sh
python3 mac_backup_key.py --host siteadmin@192.168.1.20 --project-dir /volume1/docker/gift-ledger --project gift-ledger --generate "$HOME/往来有礼备份.agekey"
```

如果想沿用已有的 age 钥匙，省略最后的 `--generate` 及其路径，在弹出的窗口选原文件即可。看到“本站备份钥匙登记通过”后，请单独保管 Mac 上的原钥匙。此后 Ubuntu 的备份命令或群晖的手动备份任务均可自行运行。

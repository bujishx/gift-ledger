# 往来有礼 · 从备份恢复

这份说明用于把账本带到另一座新站。先准备一个已启动、尚未注册用户的空站，记下它的 HTTPS 网址、项目名和 YAML 所在的文件夹。若旧站仍在使用，请先暂停记账并做最后一次备份，记下最后一笔和当时的收支合计，方便核账。

## 准备备份和钥匙

1. 找到备份成功时显示的整份加密备份。单份 YAML 站点的成品在站点文件夹的 `backups/artifacts/备份编号/` 中。把整个编号文件夹保存到自己的电脑或另一块盘。旧工具导出的五文件 ZIP 也可以直接选择。
2. 准备**创建这份备份时对应的 age 私钥**，与备份分开保管。选择本机或直连盘上的私钥文件，保存在自己的账号专用位置。
3. 新站启用 SSH，准备好能在新站运行 Docker 的 SSH 账号。初次连接时核对本站的 SSH 主机指纹。项目目录是服务器上的绝对路径，例如群晖的 `/volume1/docker/gift-ledger` 或 Ubuntu 的 `/srv/gift-ledger`。项目名与建站时使用的名称一致。

提供本站维护说明的发行版会生成 `data/本站维护说明.txt`。请打开**新建目标站**的这份文件，记下它的网址、项目名、实例和项目文件夹。若文件夹尚未显示，先在目标服务器执行“查看本站目录”，再重新打开文件。

## 在 Windows 登记钥匙或恢复

将同版本的 `windows-site-tools.zip` 全部解压到本机。准备 Python 3.9 或以上版本。用过旧版便携工具的站主，也可将已核对的整份 `windows-runtime` 或 `runtime` 文件夹复制到 `GiftLedger.cmd` 旁边。

Windows 需要本机的 `age.exe` 和 `age-keygen.exe`，或已运行、使用 Linux 容器的 Docker Desktop。使用 Docker 时，工具会从 Docker Hub 取得缺少的本版本备份镜像。SSH 密码登录请使用 PuTTY 的 `plink.exe`。使用已有 SSH 登录密钥时，也可通过 Windows OpenSSH 登录一次并核对网站服务器的 SSH 指纹，再运行工具。

双击 `GiftLedger.cmd`，选择登记或恢复。先输入 SSH 登录地址，例如 `admin@192.168.1.20`。SSH 端口默认是 22，按回车即可；服务器改过 SSH 端口时，填实际值。再输入服务器上的 YAML 文件夹和项目名。恢复确认框会另外显示新站的 HTTPS 网址，供你与建站时记下的地址核对。

- **第一次备份**选择“登记日常备份钥匙”。工具会同时显示“生成新钥匙并登记”和“登记旧钥匙”。按自己的选择创建文件或打开已保管的原文件。看到登记成功后将原钥匙单独保管。
- **恢复**选择恢复到独立空站。在文件窗口选择整包 ZIP 或五文件目录里的 `BUNDLE.json`，再选择匹配的原钥匙。在确认框中核对源站、笔数、目标网址和实例，点“确定”开始。窗口会显示当前步骤。遇到服务器管理员授权提示，在该提示处输入密码，输完回车并等待步骤更新。

出现“恢复成功”表示新站的账本和应用文件已通过校验。工具显示的是全站所有账号合计的笔数。按弹窗指引完成临时文件清理，再用原网站账号和网站密码登录新站，核对自己账号的最后一笔及收支合计。若中途连接断开，用相同的备份和同一个目标重新打开入口。

## 在 Mac 选择备份，确认目标

在 Mac 打开同版本的恢复工具目录。工具需要 Python 3、SSH、`age` 和 `age-keygen`，也可使用已经启动、已载入该版本备份镜像的 Docker Desktop。从**新站**的 `data/本站维护说明.txt` 找到“恢复到本站”，复制整段命令。目标网址、项目名、项目文件夹、站点目录和 YAML 已经填好。使用下面的通用示例时，请填入目标新站的项目目录、项目名和 SSH 账号。

```sh
python3 mac_restore.py --host siteadmin@192.168.1.20 --project-dir /volume1/docker/gift-ledger-restore --project gift-ledger-restore
```

在终端拖入备份目录或 ZIP，按回车。也可以直接回车打开文件窗口，或输入 `d` 打开目录窗口。轮到原钥匙时同样可以拖入文件或按回车选择。窗口关闭时，终端会留在当前步骤，可粘贴路径继续。已有完整路径时，将 ZIP 路径放在 `mac_restore.py` 后，再加上 `--key "$HOME/往来有礼备份.agekey"`。

首次密码提示用于 SSH 登录。后续管理员授权提示会显示正在执行的步骤。先看菜单栏输入法，英文密码选 ABC，输入时终端不会显示字符。程序核验五件文件、实际解密，并检查目标有没有已有账本。看到源站名称、笔数、目标网址和目标实例后，核对网址，输入“恢复”。若要在写入前退出，直接回车。连接中断后，用同一份备份和同一目标再次运行。

## 核账后切换

看到“已核对 … 笔往来”后，用手机或电脑打开**新站**网址。按一页安装说明核对并信任新站自己的公开证书，用旧站的账号、原密码登录，核对最后一笔、收支合计，以及自己熟悉的联系人和事件。核对一致后，再把日常记账入口切换到新站。

群晖里新旧站的证书都叫 `本站根证书.cer`。从新项目的 `data` 目录下载，打开新站维护说明，逐位核对“核对公开根证书”给出的 SHA-256。若 DSM 的 `prepare` 日志页为空，使用该段 SSH 命令。Mac 下载目录已存在同名文件时，新文件可能带有 `(1)` 等后缀。

## 用旧备份恢复的新站，今后怎样备份？

如果你今后在**用旧备份恢复的新站**记账，就打开这个站的 `data/本站维护说明.txt`。恢复时提供的旧钥匙用来解密旧备份，工具会在恢复收尾时清理临时副本。这个站首次备份前，按“第一次备份前登记钥匙”打开登记工具，在菜单里任选一种。若这个站已显示过“本站备份钥匙登记通过”，可直接做手动备份。

- **登记旧钥匙。** 提供刚才恢复旧备份用的 `.agekey` 原文件。以后用同一把钥匙，就能恢复这份旧备份和用旧备份恢复的新站今后产生的备份。
- **生成新钥匙并登记。** 用新钥匙恢复这个站今后产生的备份，用旧钥匙恢复当初迁站用的旧备份。请分别保管两份 `.agekey` 原文件，记下各自对应的备份。

登记成功后，从**用旧备份恢复的新站**的维护说明复制“手动备份”。在群晖为这个项目建立备份任务，运行一次。看到“已实际解密核验”后，将本次编号目录里的五个文件一起保存到另一台设备。钥匙原文件与备份分开保管。以后备份直接运行这项任务。

## 在 Mac 首次登记日常备份钥匙

从零建账的新站和用旧备份恢复的新站，使用同一个首次登记入口。打开**要备份的那个站**的维护说明，复制“第一次备份前登记钥匙”里的整段 Mac 命令，到同版本的 Mac 站主工具目录运行。看到两种选项后，由你决定用哪一把。

- **登记旧钥匙。** 将自己保管的 `.agekey` 原文件拖入终端，或按回车打开文件选择窗口。可以使用你在别的站用过的备份钥匙。
- **生成新钥匙并登记。** 确认工具显示的保存位置，或输入新的文件路径。工具会创建钥匙并将它登记到本站。

下面这条通用示例也会打开同一个选择菜单。使用示例时，请更换 SSH 地址、项目路径和项目名。

```sh
python3 mac_backup_key.py --host siteadmin@192.168.1.20 --project-dir /volume1/docker/gift-ledger --project gift-ledger
```

如果钥匙文件已经生成但登记中断，再次运行同一条命令，选择“登记旧钥匙”，选取刚才生成的文件即可继续登记。看到“本站备份钥匙登记通过”后，请单独保管这份原文件。以后可直接运行本站的备份任务。

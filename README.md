# 往来有礼

在家中局域网或 VPN 上为自己和家人部署礼金账本。首版支持 Linux/amd64 的 Ubuntu 与群晖 Container Manager。[English](README.en.md)

## 安装

从同一发行版本下载一个 [docker-compose.yml](https://github.com/bujishx/gift-ledger/releases/latest/download/docker-compose.yml)。在专用空目录中保存它，用文本编辑器将顶部的局域网 IP 和端口改为本站的地址，例如 `192.168.1.20` 和 `8443`。在线安装时服务器需要能下载发行版指定的镜像。使用离线候选包时，先按包内说明核对并导入配套镜像，再使用包内同一份 YAML。

- **Ubuntu** 在 YAML 顶部的 `name:` 填写项目名。已安装 Docker Engine 与 Compose 插件后，在 YAML 目录执行 `docker compose up -d`。
- **群晖** 在 File Station 建一个专用空文件夹，例如 `/volume1/docker/gift-ledger-family`，把 YAML 放进去。在 Container Manager → 项目 → 新增中填写项目名，选择该文件夹并使用已有 YAML。文件夹名可以自取。为方便以后在终端操作，建议 YAML 顶部的 `name:` 和群晖项目名填成一样。

同一台主机再建独立站时，请另取项目名、使用另一个空闲 HTTPS 端口，并选择另一个专用空文件夹。两个站可以使用同一个局域网 IP。默认数据和备份都在各自的文件夹下。

安装完成后，在站点文件夹打开 `data/网站地址.txt` 和 `data/本站维护说明.txt`。后者列出本站网址、项目名、实例以及可直接复制的维护命令。网页维护首次启用时，在本站服务器管理员终端执行“启用本站网页维护（每站一次）”中的整段命令。看到“本站维护服务已就绪”后，Ubuntu 已设置开机启动。群晖还需按该节保存本站的开机触发任务。

把同目录的 `本站根证书.cer` 送到手机或 Mac，按“核对公开根证书”比对 SHA-256 后再信任。DSM 的 `prepare` 日志页为空时，说明中的命令可从 SSH 读取日志及服务器文件的指纹。同名下载可能带有 `(1)` 等后缀，按指纹选择。手机连接局域网或 VPN，打开网址，注册、完成本人建档、记一笔。

在 Mac 上将指纹已核对的根证书导入“登录”钥匙串。打开“钥匙串访问”，在“证书”列表中双击本站的 `GiftLedger Site CA` 证书，展开“信任”，将“安全套接字层（SSL）”设为“始终信任”。关闭详情窗口，按系统提示确认，再打开本站网址。[Apple 钥匙串访问指南](https://support.apple.com/zh-cn/guide/keychain-access/kyca11871/mac)

重启服务器后，用原账号登录并核对这笔账。忘记账号或密码时联系本站站主。已安装的 YAML 固定镜像摘要，站主自行选择升级时间。

## 在浏览器备份与恢复

1. **登录本站维护页。** 用 Windows、Mac 或 Ubuntu 桌面的浏览器打开维护说明中列出的地址。它与记账网站使用相同的 IP 和端口，网址末尾是 `/maintenance`。在服务器管理员终端运行“站主维护登录码”中的命令，核对项目和网址，输入短时码。也可以在页面上设置站主密码，忘记时用新的短时码重设。
2. **登记本站日常备份钥匙。** 从零建账的站和用旧备份恢复的新站都可以选“登记旧钥匙”或“生成新钥匙并登记”。选择旧钥匙时，打开电脑或 U 盘中保存的原文件，例如 `identity.txt` 或 `.agekey`。生成新钥匙时，先下载保存，再选中刚保存的文件。点“确认登记到本站”，等到出现“本站备份钥匙登记通过”。
3. **备份并核账。** 点“开始备份”。网站会短暂停用，稍后回到同一维护页点“查看备份结果”。核验成功后点“下载已核验的备份 ZIP”，与对应的原钥匙分开保存。用原账号打开记账页，核对最后一笔和收支合计。
4. **把旧备份恢复到独立空站。** 建立另一个项目，使用另一端口和空文件夹。保持目标站尚未注册账号，从**目标站**的维护页选择旧站备份和制作备份时的原钥匙。点“上传并预检”，核对源站、笔数、目标网址和项目，输入“恢复”，再点“确认恢复到本站”。用原账号登录恢复后的站点核账。接下来在用旧备份恢复的新站首次备份时，可沿用旧钥匙，也可生成新钥匙。[完整恢复步骤](docs/从备份恢复.md)

**网页暂时打不开时**，打开服务器上的 `data/本站维护说明.txt`，运行“网页暂时打不开时查看本站维护任务”中的命令。按原任务编号核对进度和救援说明。需要使用终端时，本站维护说明也提供手动备份命令和同版桌面工具的登记、恢复命令。[Mac 站主工具](https://github.com/bujishx/gift-ledger/releases/latest/download/mac-site-tools.zip) · [Windows 站主工具](https://github.com/bujishx/gift-ledger/releases/latest/download/windows-site-tools.zip)

群晖手动备份支持 Container Manager 24.0.2-1543 和 24.0.2-1606，任务启动时会校验套件文件。若显示 `CM_vendor_file_set_unreviewed`，此项检查会在停站前结束任务。请反馈套件中心显示的 Container Manager 版本号和任务计划中的运行结果。

## 证书到期与续签

新建站点或续签时，网站 HTTPS 证书有效 **365 天**。旧证书继续使用到当前到期日，续签后采用新期限。打开 `data/本站维护说明.txt`，运行“查看证书有效期”可看到网站证书和根证书各自的到期时间。

**Ubuntu** 在启用本站网页维护时安装并启用证书定时任务，每天按服务器当地时间 03:15 检查。可按维护说明中的“Ubuntu 自动续签网站证书”查看下次检查时间和上次结果。

**群晖只需为每个站设置一次排程。** 按维护说明中的“群晖自动续签网站证书”新建并启用每天运行的任务，例如每天凌晨 03:15。网站证书还剩 30 天或更短时才续签，换证时网页会短暂停用。若已设置 DSM 邮件通知，可在任务中选择仅在脚本异常终止时发送运行详情。需要在群晖上立即换证时，可运行“续签本站 HTTPS 证书”，再从原网址核对新到期时间。[群晖任务计划说明](https://kb.synology.com/zh-cn/DSM/help/DSM/AdminCenter/system_taskscheduler?version=7)

本版新建站点的根证书到公元 **9999 年 12 月 31 日 23:59:59 UTC**。已有站点保留原根证书及原到期时间。换发网站证书会沿用本站根证书，已信任它的设备可继续访问原网址。若工具提示现有根证书有效期不足以签发完整的 365 天网站证书，请在当前网站证书到期前备份并恢复到独立新站，核账并信任新站根证书后切换。早期版本请先按指南升级。[升级与回退](docs/站主升级.md)

站主可查阅[账号找回](docs/站主找回账号.md)和[升级与回退](docs/站主升级.md)。
